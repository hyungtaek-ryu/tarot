# 달빛 타로 🔮

Gemini AI로 타로 리딩을 해주는 웹앱입니다. 설치나 서버 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 리딩 6단계
1. **질문 구체화** — AI가 카드를 뽑기 전에 질문을 먼저 살펴봅니다.
   - 모호하거나 예/아니오 질문이면 기간·대상·맥락이 담긴 질문을 제안
   - 30일 안에 같은 사안을 다시 물으면(임베딩 유사도 + 기록) 감정을 먼저 알아주고 역질문을 제안, 바로 뽑지 않음
   - 건강·법률·극단적 투자·자해 관련 질문은 리딩 대신 전문가 안내 (위기 키워드는 상담전화 109 안내)
   - 질문에 맞는 배열법 추천
2. **셔플** — 리플 셔플 / 워싱 셔플 (정·역방향은 50:50으로 정해지고, 워싱 때 다시 섞임)
3. **덱 정돈 및 컷** — 세 묶음 중 합칠 순서를 직접 선택
4. **뽑기 및 배치** — 부채꼴로 펼친 덱에서 고른 카드를 뒷면 그대로 배치
5. **오픈 및 리딩** — 배치 순서대로 뒤집고, AI가 상징·포지션·카드 간 흐름을 종합 해석. 이후 대화형 추가 질문
6. **마무리** — 카드를 정돈하고 다시 볼 시기(1~3개월, 또는 상황 변화 후)를 안내

배열법: 원 카드, 쓰리 카드(과거-현재-미래 / 원인-현재-해결책), 켈틱 크로스(10장)

## 구성
```
index.html        화면 구조
css/style.css     디자인 / 애니메이션
js/cardback.js    카드 뒷면 SVG 문양
js/cards.js       지식 베이스: 78장 키워드·원소·점성·수비학·그림 속 상징, 배열법 정의
api/gemini.js     Vercel 서버 함수: API 키를 숨긴 Gemini 프록시 + 횟수 제한
js/gemini.js      AI 파이프라인: 의도 파악, 임베딩 유사도, 리딩 프롬프트(카드 간 흐름 계산), 사후 질의
js/app.js         단계별 화면 로직 (카드 추출은 crypto 난수로 앱에서 처리)
cards/            라이더-웨이트-스미스 카드 이미지 (1909년판, 퍼블릭 도메인, Wikimedia Commons)
```

## Vercel 배포
1. 이 폴더를 GitHub 저장소 **맨 위**에 올립니다 (`index.html`이 저장소 루트에 오도록).
2. Vercel 대시보드 → Add New → Project → 저장소 Import. Framework Preset은 **Other**, Build Command는 비워 둡니다.
3. **Settings → Environment Variables**에 아래 값을 넣고 다시 배포(Redeploy)합니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | ✔ | [Google AI Studio](https://aistudio.google.com/apikey)에서 발급한 키 |
| `GEMINI_MODEL` | | 리딩 모델 (기본 `gemini-flash-latest`) |
| `RATE_LIMIT` | | IP당 10분 동안 허용할 요청 수 (기본 40) |

API 키는 서버 함수(`api/gemini.js`)에서만 쓰이고 브라우저에는 전달되지 않습니다.
키를 코드나 파일에 직접 적어 커밋하지 마세요.

## 참고
- `index.html`을 파일로 직접 열면 AI가 동작하지 않습니다 (서버 함수가 없기 때문). 배포 주소나 `vercel dev`로 확인하세요.
- 리딩 기록(반복 질문 감지용)은 방문자 브라우저의 localStorage에만 저장되며, 설정 창에서 지울 수 있습니다.
- 횟수 제한은 서버 인스턴스 메모리 기준이라 완벽하지 않습니다. 사용량이 많아지면 Google AI Studio에서 키의 사용 한도·결제 알림을 꼭 설정하세요.
